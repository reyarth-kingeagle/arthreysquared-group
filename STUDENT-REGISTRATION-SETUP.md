# CET154 Student Registration to Section Google Sheets — Pilot Setup

## What the student account means in this phase

Students authenticate through a Google Form configured to collect **Verified** school-account email addresses. They enter family name, given name, middle initial, student ID, and section. **No custom website passwords or passcodes are stored.** Registrations are placed in a **PENDING INSTRUCTOR APPROVAL** state. Protected quizzes and official grading are not active.

The Google Forms owner must be the instructor's authorized Google account. Student-facing Google Forms responder links may be public; **student spreadsheets, private registry, and this MASTER must never be shared with students**. The originally shared ARTHREYSQUARED Drive hierarchy allowed **anyone with the link to edit**. A separate owner-only LMS storage folder has therefore been created outside that hierarchy and its master Sheet has been moved there. Verify the new folder stays **Restricted** before entering real student data. Never store grades in the original public/shared Drive folder.

## Data integrity

- Each registration receives an immutable Student UID (UUID).
- A private registry prevents duplicate ID/email enrollment; section changes are queued for instructor review.
- Student Dataset is **sorted as a full 9-column row**, surname, given name, then student ID.
- Score Ledger stores scores under Student UID + Assessment ID, **never a spreadsheet row number**.
- Grading System is regenerated by joining the correct UID and does not store manual score inputs. It currently shows provisional point evidence only; official grades and CO percentages remain blank pending the approved grading engine.
- One separate section Sheet per section; each section's scores remain isolated.

## Step 4 — Generate the section spreadsheets and form

1. In Apps Script's function dropdown select setupCET154.
2. Click Run; authorize the script after reviewing its Drive, Sheets and Forms permissions.
3. Open Execution log / Executions.
4. You should see an owner-only Google Form edit URL, a responder URL, and a spreadsheet URL per section.
5. Check that the newly created section Sheets are in the private CET154 folder and have separate Student Dataset and Grading System tabs.
6. The script also creates a separate private student registry. Its email/ID uniqueness check prevents automatic reassignment to a different section.
7. The script installs the Form submit trigger and a Score Ledger edit trigger for each section. New students are only added after the form is open.

Setup is designed to avoid duplicate form/sheet creation on repeated runs. Keep the pilot to a small number of sections because Apps Script trigger, execution and quota limits apply.

## Step 5 — Make email collection VERIFIED before accepting responses

This is required for identity security.

1. Open the generated form's **edit URL** (not its responder URL).
2. Open Settings > Responses.
3. Set Collect email addresses to **Verified**, not Responder input.
4. Check that Limit to 1 response is enabled.
5. Review the questions: Family Name, Given Name, Middle Initial (optional), Student ID Number, Section.
6. Publish the form if Google requires publishing, and only then enable Accepting responses.
7. Test the responder URL in a separate signed-in browser. Students must confirm the Google account whose address is collected.
8. The script additionally rejects email addresses outside the school domain @g.msuiit.edu.ph. Incorrect section names or student IDs are also rejected. Names and ID numbers are still instructor-verified.

Important: Code can enable email collection but Google Forms' verified-vs-manual collection setting must be checked in the Google Forms editor. Do not distribute the form until this check is complete. If the institution limits external Forms use, coordinate with the Google Workspace administrator.

## Troubleshooting and important limitations

- If the student is missing, inspect Apps Script Executions and the registry Audit tab for rejected/failed entries.
- If school ID/email already exists, the registration is flagged for instructor review; prior grades are not overwritten.
- If Score Ledger contains a duplicate Student UID + Assessment ID, unknown UID, blank scores or earned points higher than maximum, the grade identity rebuild rejects invalid evidence.
- If the Form is closed, setup intentionally disables responses until the instructor verifies Google Forms email settings.
- If names or scores do not match, check UID, not row positions, and run refreshAllCET154Views as instructor after repairing the data.
- If a trigger was interrupted between writing the section roster and the central registry, first inspect the affected student UID and IDs, then run reconcileCET154Registrations as the script owner. It repairs only consistent, nonconflicting registry/section links and refuses conflicting IDs. Never rerun unverified/duplicate form responses to force a merge.
- Do not rename/remove section Sheets without updating Script Properties and transfer procedures.
- This milestone DOES NOT provide website passcode login, approved enrollment workflows, automatic student grade/CO computation, secure Moodle-like quiz access, or PDF reports. Those come after the registration pilot succeeds.

## Critical: original Drive folder access

The original 'Arthreysquared-group Website' Drive folder and its MSU-IIT subfolder currently have a Google Drive permission of **Anyone with the link — Editor**. This is not appropriate for private student data. The CET154 MASTER was moved to the independent private folder above, and **new section spreadsheets generated by this script will also be created there**.

If you do not intentionally want the original teaching-materials folder to be publicly editable, open that original folder in Google Drive → Share → General access → change **Anyone with the link** to **Restricted** (or at least remove public edit rights) → Save. This may affect other links you shared, so review before changing it. The student registry and grade data must stay in the newly verified private folder regardless.
